## 📌 Project Overview

This project involves the development of a cloud-based portfolio website hosted on a Microsoft Azure Virtual Machine. The purpose of this project is to demonstrate practical skills in configuring, deploying, and managing a Linux-based web server using Infrastructure as a Service (IaaS).

The virtual machine is configured using SSH key authentication and runs the Nginx web server to host a custom HTML webpage. Additionally, a domain name is linked to the server using Cloudflare DNS, allowing access through both the public IP address and a user-friendly domain.

This project builds on foundational cloud computing concepts and demonstrates the ability to deploy, manage, and troubleshoot a live server environment.
