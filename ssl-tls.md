# SSL/TLS Configuration

## Overview

To improve website security and professionalism, HTTPS encryption was enabled for the portfolio website using Cloudflare SSL/TLS services.

This ensures that traffic between the user and the website is encrypted and securely transmitted across the Internet.

---

# SSL/TLS Benefits

Implementing SSL/TLS provides several important security and usability benefits:

- Encrypts communication between users and the web server
- Protects data from interception during transmission
- Improves website trustworthiness and professionalism
- Enables HTTPS secure browsing
- Helps prevent browser security warnings

---

# Cloudflare SSL/TLS Integration

Cloudflare was used to manage the DNS configuration and HTTPS encryption for the website domain.

The domain was successfully configured to use:

```text
https://www.ict171project.com
```

The website now displays a secure HTTPS connection through the browser.

---

# Verification

SSL/TLS functionality was verified by:

- Accessing the website through HTTPS
- Confirming browser padlock security indicator
- Testing successful webpage loading using the domain name

Successful verification confirmed that encrypted HTTPS communication was functioning correctly.
